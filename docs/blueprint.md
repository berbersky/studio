# **App Name**: Remote Commander

## Core Features:

- Add Server Connection: Add a new remote server connection by providing the required connection details such as server IP, username, and password.
- Edit Connection Details: Modify existing connection details such as the IP address, username, password, and any notes associated with the connection.
- Launch Remote Session: Initiate a remote desktop session to the selected server.
- Group Connections: Organize and group connections into logical categories for easier management, supporting an arbitrary number of groups, as well as drag-and-drop reassignment between them.

## Style Guidelines:

- Primary color: Deep dark blue (#1E3A8A) to evoke professionalism and security.
- Background color: Dark gray (#242526), creating a sleek, modern interface.
- Accent color: Light silver (#D1D5DB) for highlights, buttons, and interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, suitable for both headlines and body text, creating a modern look.
- Use simple, line-style icons in light silver to represent server actions and connection statuses.
- Design a clean and structured layout with a sidebar for server groupings and a main panel for connection details.
- Implement subtle transitions and animations to provide feedback on user interactions, such as launching or editing a connection.
